Где практика лучше макетов

Макет показывает один момент. В работающем приложении есть время, пустые состояния, плохая сеть и узкий экран, и там решения пришлось додумать.

Время и данные

  • Дни недели и «через 7 месяцев» считаются от настоящих дат. В макетах 21 и 25 октября подписаны не теми днями.
  • Свежие записи помечены «только что» или временем с прошлого визита, и пометка уходит сама.
  • Первый запуск не пустой: «Сегодня» в избранном собирает дела со сроком со всех страниц.
  • Пустые страницы, которые так и не тронули, удаляются сами.

Авто

  • Пока модель думает, чип показывает «Авто», а не угаданную заранее страницу.
  • «купить молоко и хлеб» становится двумя записями без глагола.
  • Правила не трогают текст в кавычках: «Атомные привычки» остаётся названием.
  • Порошок и прочая бытовая химия попадают в отдел «Бытовая химия».
  • Ключ проверяется у OpenAI до сохранения. Без сети ключ сохраняется и проверится при первой записи.
  • SDK OpenAI загружается, только когда есть ключ: без ключа эти 81 КБ не скачиваются.

Телефон

  • Доска стала полосой этапов, таблица показывается карточками.
  • Календарь показывает месяц с точками и дела выбранного дня под ним.
  • Результат поиска открывается превью и не уводит со страницы.
  • Экспорт уходит в системное «Поделиться»: сразу в Файлы или в мессенджер.
  • Переключатели, чипы и сегменты нажимаются в зоне 44 px, даже если сами меньше.

Надёжность

  • Удаление отменяется из уведомления, удалённое лежит в корзине 30 дней.
  • Приложение ставится на экран и открывается без сети.
  • Браузер можно попросить не стирать данные при нехватке места.
  • Превью, поиск и окно ключа живут в адресе, поэтому жест «назад» закрывает их и не уводит со страницы.
  • Работает на любом статическом хостинге, в том числе с адресами вида /chat/.

Мелочи

  • Иконки тоньше, линия 1,75 вместо 2, ближе к макетам.
  • Цифры моноширинные только там, где выстраиваются в столбик: время, количества, счётчики.
  • Меню возвращает фокус правильно: «Переименовать» из «⋯» сразу ставит курсор в поле.
  • Доска и таблица на десктопе занимают всю ширину.

Что нашла сверка

Каждое расхождение со снимком разбиралось до причины. Вот что оказалось ошибкой приложения и исправлено в этом же PR.

  • Если хостинг отдаёт адрес со слешем (/chat/), вкладка «Чат» не подсвечивалась, а превью закрывалось сразу после открытия. Теперь адрес выравнивается при входе.
  • Переключатель не реагировал на нажатие по центру: зона касания 44 px лежала на обёртке и перехватывала нажатие. Теперь она на самой кнопке у всех переключателей.
  • После отправки с главной карточка «Разбирается…» не появлялась до ответа модели.
  • Заметка в карточке записи стояла с двойным отступом, а одиночный подпункт дублировался полоской прогресса.
  • Превью страницы в поиске показывало вкладки и кнопки выбора из Входящих. Теперь это компактный список.
  • Запись, открытая в панели справа, не подсвечивалась в карточке чата.
  • Цвет панели браузера был записан отдельно от токенов. Теперь он читается из --bg.
  • Раньше в этой же работе: переименование секции из «⋯» теряло фокус, а Enter на десктопе создавал страницу; «купить молоко и хлеб» превращалось в одну запись «Купить молоко»; «Как в системе» и «Настройки» обрезались на узком экране; системная кнопка очистки поиска дублировала свою.

Чего не было в макетах

Экраны, которые макеты описывают словами или не описывают вовсе. Тема снимков переключается там же, выше.

Тема: одно место для цветов

Nuxt UI не перекрашивается поверх, а получает значения через собственные переменные и конфиг. Поэтому любой новый компонент Nuxt UI сразу выглядит как Cerulean, а смена цвета делается в одном файле.

  1. tokens.cssЦвета светлой и тёмной темы по таблице «Цвета» из принципов. Единственный файл с цветовыми значениями.
  2. main.cssПереводит токены в переменные Nuxt UI и утилиты Tailwind (bg-canvas, text-accent-ink). Здесь же шкала шрифтов и радиусы.
  3. app.config.tsФорма компонентов Nuxt UI: кнопки, поля, select, переключатели, меню, листы, диалоги, подсказки, тосты. Только классы из шага 2.
  4. компонентыПишут смысловые имена: text-toned, bg-elevated, rounded-card. Ни цветов, ни произвольных размеров.

Как проверено

  • Поиск по app/: шестнадцатеричные цвета есть только в tokens.css. Исключения две: манифест PWA в nuxt.config.ts, которому нужно готовое значение, и чёрная альфа-маска для затухания края списка.
  • !important только в правиле для prefers-reduced-motion.
  • :deep и переопределений стилей Nuxt UI через CSS нет.
  • Проп :ui на месте встречается 12 раз, и только для размеров и раскладки: ширина окна, высота листа, моноширинный шрифт в поле ключа.
  • Цвет панели браузера читается из --bg и меняется вместе с темой.

Как устроено

  • Nuxt 4 без сервера (ssr: false), Vue 3.5, Nuxt UI 4, Tailwind 4, Pinia. Автоимпорт выключен: каждый файл импортирует то, что использует.
  • Данные в IndexedDB, приложение работает целиком в браузере. PWA кеширует всё, поэтому открывается без сети и ставится на экран.
  • Авто: сначала правила на устройстве (списки, глаголы, даты, описания страниц). Если они не уверены и есть ключ, решает модель OpenAI, быстрая или точная. Без сети запись ждёт во Входящих и разбирается, когда сеть вернётся. Если места не нашлось, Чат спрашивает.
  • Один компонент на оба размера: меню «⋯» это лист на телефоне и выпадающий список на десктопе, превью это лист или панель справа, поиск это полный экран или палитра.
  • Открытые слои живут в адресе: ?peek= превью, ?find поиск, ?key окно ключа. Системный жест «назад» закрывает их.

Чего нет и что отличается

Связи между записямиВ карточке записи нет колонки «Связано», подпункт не может лежать на другой странице. Для этого нужна модель связей в данных.
Правка в превьюЛист и панель справа только читают и отмечают. Заметка и свойства правятся после «Открыть». Следующий шаг: разрешить их в панели на десктопе, как в макете.
Доске нужно свойство «Выбор»Если его нет, вместо доски карточка «Для доски нужно свойство «Выбор»» с кнопкой «Добавить свойство».
СинхронизацияЕё нет: данные между устройствами переносятся экспортом JSON.
Вес первой загрузки347 КБ JS в gzip, большая часть это Vue и Nuxt UI. После первого входа всё лежит в кеше, но первый вход по мобильной сети можно ускорить, разбив код по экранам.
ДиктовкаРаботает через распознавание речи браузера. Где его нет (Firefox), на месте микрофона кнопка отправки.
Редактор текстаTiptap пока не подключён: заметки простым текстом, как в макетах.
