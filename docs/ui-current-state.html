Что сделано

  • Утверждённая пара тем: светлая «Строгий, плоский» и тёмная ночная, с ролями elev, panel, chip, warn-fill. Цвета только в tokens.css.
  • Правила «Меньше шума»: значки без плашек (плашка только в шапке страницы), счётчики простым текстом, кнопки без рамок.
  • Правки v16-app-sync и ревью v19: тексты, второй вид у Целей, связь Полумарафона, Корзина с подтверждением.
  • Главная v20: шапка с «⋯», секция Недавнее, сворачивание секций, компактный режим без статусов, «⋯» у строки и долгое нажатие.
  • Правки Fable: поле не прыгает при наборе, клавиатура не закрывается после отправки, серия «3 записи → Продукты», «Отменить» возвращает текст.
  • Полноэкранный Поиск на телефоне и один выбор страницы с поиском вместо четырёх.
