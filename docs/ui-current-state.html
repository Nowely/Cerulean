Наблюдение · подтверждено кликом

Search и верхний Notes пока не переключают экран

При нажатии меняется только подсветка кнопки. Основная панель и список тредов остаются на месте. Экран заметок доступен, если открыть тред Personal Notes.

Наблюдение · по снимкам

Основные экраны открываются выбором треда

Выбор Website Redesign, Marketing Launch, Personal Notes, Groceries или Team Contacts меняет основной экран на соответствующий тип содержимого.

Состав данных

Чеклист есть в форме, но отсутствует среди стартовых примеров

Тип Checklist предлагается при создании треда и отображается тем же экраном списка, что и Shopping. В seed-наборе отдельного треда checklist нет.

Визуально

Текущие списки компактные, рабочая область широкая

При 1440 × 960 карточки занимают только верхнюю часть панели. На снимке задач четыре пункта и много свободного места; это может быть следствием небольшого демонстрационного набора.

Дефект · подтверждён UI и данными

Будущие сроки показаны как «Due just now»

Например, задача Design new homepage hero section имеет срок через три дня, но на экране пишет just now. Форматирование срока ошибочно обрабатывает даты в будущем.

Данные и границы отчёта

Хранение
Клиент использует IndexedDB в браузере (cerulean-blocks); при пустой базе загружает стартовые seed-данные.
Удалённый API
В просмотренном слое Client/app используется локальная модель. Сетевая синхронизация с сервером этим осмотром не подтверждена.
Осмотрено
Production build, боковая панель, выбор пяти типов тредов, форма выбора типа нового треда, верхние кнопки Search и Notes.
Не проверялось
Мобильный экран, тёмная тема, завершение форм и сохранение после перезагрузки браузера.
Результат сборки
Успешно: Nuxt собрал клиент и сервер и prerender-нул главную страницу. Сборка выдала предупреждения о загрузке каталогов шрифтов, локали i18n и sourcemaps; они не остановили сборку.
