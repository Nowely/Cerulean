# Запасы: предложение для прототипа

## Включение на существующей странице

Состояние `#i3stocksetup`: у страницы «Покупки» уже есть записи и настроенный вид «На неделю», но отслеживания запасов ещё нет.

1. Нажать активную вкладку «Купить» → «Настроить вид» → **«Включить запасы»**.
2. Подтверждение объясняет: добавятся вид «Запасы» и свойства для остатка и нормы; существующие записи, виды и настройки останутся без изменений.
3. «Отмена» ничего не меняет. «Включить» добавляет вид, не заполняя остатки товаров автоматически. Текущая вкладка, записи и прежние вкладки остаются.
4. Открыть товар → «+» → «Осталось» и задать значения только для него.

Прямой экран подтверждения: `#i3stocksetupconfirm`. Это пример страницы без конфликтующих свойств; сценарии, когда свойства или вид с похожими именами уже существуют, требуют отдельного проектирования перед реализацией в приложении. Прототип не является проверкой сохранения реальных настроек или данных.

## Один редактор значения

- На карточке товара нажать значение «Осталось» — открывается `#i3stockedit`.
- В таблице `#i3stocktable` нажать ячейку «Осталось» — открывается тот же редактор для той же записи.
- Поля: **«Осталось»**, **«Норма»**, **«Единица»**. «Готово» применяет значения к записи, «Отмена» закрывает без изменения.
- В списке остаётся компактное `3/5`; тап раскрывает быстрые `− / +`. Изменение в любом представлении видно в остальных без изменения других записей.
- Единица меняется без автоматического пересчёта чисел. В примере пустой новой записи показано `шт` как предлагаемый вариант по умолчанию; возможность выбрать значение по умолчанию для свойства и точная семантика пустой единицы ещё не спроектированы.
- Поле принимает десятичную запятую; точные ограничения ввода и обработка старых отрицательных или больших значений остаются вопросом реализации, а не утверждённым продуктовым правилом.

## Согласованное поведение

Запас считается заканчивающимся, если остаток не больше 1 и меньше нормы: `0/1`, `1/5` и `0,5/2` — мало; `1/1` и `0,5/0,5` — нет. После покупки `0/1` превращается в `1/1` и выходит из «Купить». Срок годности и автоматическая покупка по дате в этом сценарии не используются.

Если ввести товар, уже существующий в «Запасах», но отсутствующий в «Купить», возвращается та же запись без изменения остатка. Например, `5/5` остаётся `5/5`; отмена восстанавливает состояние записи до повторного ввода.

## Проверки прототипа

При запущенном локальном сервере и установленном в `Client/` Playwright:

```sh
node tools/check-stock.mjs
```

Проверяются включение и отмена, пример сохранения вкладок и записей, редактор карточки и таблицы, дроби, граничные значения, покупка `0/1`, повторное добавление и отмена, desktop, Canvas и навигация по состояниям прототипа. Тесты прототипа не заменяют проверку `Client/`, S3, импорта или реального телефона.
